Result types & statuses

Type tells you what a record contains. Status tells you its last saved state. Neither is a live process check.

Type filter

All types
Show every record type that matches your other filters.
analysis
A multi-mesh analysis with a progress record, but no final qualification report yet. It may be running, interrupted, or failed.
benchmark
Recorded performance measurements, such as elapsed time or cache reuse. Not an acoustic qualification.
campaign
A generation search containing candidate parameters, stages, rankings and proposals for subsequent generations. Results are usually in child records.
mesh
A prepared mesh or solver job, with geometry and mesh checks. It does not itself contain a completed acoustic response.
precision test
A comparison between numerical precision settings, such as float32 and float64. Agreement does not establish mesh convergence.
proposal
A saved design or concept preview. Geometry is available, but this record has no completed acoustic analysis.
reference test
A solver check against a known reference, such as an analytical piston. It tests the solver, not the candidate’s coverage.
resource test
A record of runtime, sampled memory use, exit status or resource limits. It is not an acoustic accuracy test.
response
Saved horizontal/vertical acoustic data, often from an individual mesh level or standalone solve. Check its status before treating it as validated.
screening
A fast campaign’s single-mesh candidate result. Its score and rank are provisional; mesh convergence has not been established by screening.
validation
An analysis with a final mesh-qualification report. This type includes both converged and unconverged results; inspect the status.

Status filter

All statuses
Do not restrict records by status.
Mesh converged
The reference check and mesh-resolution requirement passed, and changes between the final two meshes met the comparison limits at the sampled frequencies. This does not mean coverage targets were met or the physical speaker was validated.
Reference validated
The solver reference check passed, but this response has no passing mesh-convergence qualification. It may be a single-mesh screen or an analysis whose mesh check did not pass.
Failed / blocked
Show statuses containing “failed” or “blocked”: a stage failed, or a campaign cannot continue. Open the report to see why. This filter does not include every unconverged result.
Recorded as running
Show statuses containing “running”. This is a saved label, not confirmation that a process is still alive; old interrupted runs may retain it. Analysis labels such as “mesh_ladder” are separate and are not included here.

Other labels on records

unqualified
A saved response without a convergence qualification at this record level. A raw mesh-level response can remain unqualified even when its parent validation passed.
passed / failed
The particular reference or comparison test passed or failed its criteria. For resource tests, failure can mean a nonzero exit code or a resource limit stopped the run.
inspect / recorded
Evidence is available to inspect, but the browser has not assigned an acoustic qualification. “Inspect” means a precision report did not provide an all-passed list the browser recognizes.
prepared / geometry only / proposed
A mesh, design or next-generation proposal exists. No completed acoustic response is implied.
reference_check / mesh_ladder
The last reported analysis stage: checking the reference solver or working through successively finer meshes. These can be stale after interruption.
complete; next generation proposed
The requested generations finished and the next set of candidate designs was saved. The next generation has not necessarily been solved.
interrupted; resume to continue
The campaign saved a checkpoint after interruption. Unfinished work remains.
proposed_only_not_simulated
Legacy proposal output: designs were generated without acoustic solves.
synthetic — not validation
Demonstration or artificial response data, not evidence from a physical acoustic solve.
unknown
The saved metadata does not provide a recognized status. Inspect the underlying files.

Has results

Show only records with a readable saved acoustic response. This includes screening and individual mesh-level responses, even if unqualified. It does not mean “passed”, and it does not include parent campaign records merely because their children have results.

Filters combine: a record must match every active filter. Scores should only be compared across matching frequency grids and numerical settings.
